# Downloader PDSI - Local

Sistema local de download e processamento de audios do YouTube com segmentacao e normalizacao.

## Status
Em desenvolvimento - Branch: downloader_local

## Funcionalidades Planejadas
- Download de audios (videos, playlists, canais)
- Segmentacao de audio
- Normalizacao com SOX
- Extracao de metadados
- Sistema de skip inteligente
- Suporte a batch de links

## Estrutura
```
downloader_PDSI/
├── config.py
├── input/
├── output/
├── logs/
└── src/
```

## Dependencias
- Python 3.8+
- yt-dlp
- pydub
- SOX (sistema)
